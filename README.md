# practice-pm02-integration-testing

Проект для производственной практики ПП.02.01  
**Тема курсового проекта:** Анализ качества воздуха (отображение отчётов по месяцам)

## Структура
- `module_A/` — Модуль обработки данных (AirQualityProcessor)
- `module_B/` — Модуль пользовательского интерфейса (Windows Forms)
- `docs/` — Тестовая документация и отчёт

## Как запустить
1. Открой решение в Visual Studio
2. Установи Startup Project на файл с `Program.cs`
3. Запусти (F5)
