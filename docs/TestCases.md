# Тест-кейсы для проекта "Анализ качества воздуха"

## Общая информация
- **Проект**: Анализ качества воздуха (AQI)
- **Модули**: module_A (обработка данных), module_B (UI)
- **Тип тестирования**: Модульное + интеграционное

## Тест-кейсы

**TC-001**  
**Название**: Проверка расчёта отчёта за месяц "Март"  
**Шаги**:  
1. Вызвать метод `GetReport("Март")` из класса `AirQualityProcessor`  
**Ожидаемый результат**:  
- Month = "Март"  
- AQI = 32  
- Status = "Хорошо"  
- Color = Green  

---

**TC-002**  
**Название**: Проверка расчёта отчёта за месяц "Апрель"  
**Шаги**:  
1. Вызвать метод `GetReport("Апрель")` из класса `AirQualityProcessor`  
**Ожидаемый результат**:  
- Month = "Апрель"  
- AQI = 145  
- Status = "Опасно"  
- Color = Red  

---

**TC-003**  
**Название**: Проверка обработки неизвестного месяца  
**Шаги**:  
1. Вызвать метод `GetReport("Май")` из класса `AirQualityProcessor`  
**Ожидаемый результат**:  
- Month = "Май"  
- AQI = 0  
- Status = "Нет данных"  
- Color = Gray  

---

**TC-004**  
**Название**: Проверка регистронезависимости ввода месяца  
**Шаги**:  
1. Вызвать метод `GetReport("март")` (нижний регистр)  
**Ожидаемый результат**:  
- Month = "Март" (корректно преобразовано)  
- AQI = 32  

---

**TC-005**  
**Название**: Интеграционный тест — отображение отчёта в UI  
**Шаги**:  
1. Создать экземпляр `AirQualityForm`  
2. Вызвать метод `ShowReport("Апрель")`  
**Ожидаемый результат**:  
- Текст в lblResult содержит "Отчет за Апрель", "Средний AQI: 145", "Статус: Опасно"  
- Цвет текста lblResult = Red  

---

**TC-006** (бонус)  
**Название**: Проверка, что при неизвестном месяце статус "Нет данных"  
**Шаги**:  
1. Вызвать `GetReport("Декабрь")`  
**Ожидаемый результат**: AQI = 0 и Status = "Нет данных"
